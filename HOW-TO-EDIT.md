# How this website works

This site is made of ordinary files. There is no software to install and
nothing to build. **The files in this folder *are* the website.**

---

## To see the site on your own computer

Double-click **`index.html`**.

It opens in your browser and looks exactly like the live site. Nothing is
running, nothing is being published — it's just a file on your Mac.

## To see a change you've made

Save the file, then press **Cmd + R** in the browser to reload.

## To publish

Open **GitHub Desktop**, type a short note about what you changed
(e.g. "new post about walking"), click **Commit to master**, then click
**Push origin**.

The live site updates about a minute later. If you don't see the change,
reload with **Cmd + Shift + R**.

---

## What's in this folder

| File / folder | What it is |
| --- | --- |
| `index.html` | The whole front page — hero, About, Work with me, Podcast, newsletter list, Contact |
| `posts.html` | The "all posts" page for *Well, From Here* |
| `posts/` | One file per newsletter post |
| `media/` | All photos and the logo |
| `css/style.css` | Colours, fonts, spacing — the look of everything |

Anything else in the repository is leftovers and can be ignored.

---

## Asking the AI assistant for changes

You don't need to edit the files by hand. Just describe what you want:

- *"Change the About section — here's the new text."*
- *"Add a new Well, From Here post called 'Seasons of Rest', dated today, here's the text."*
- *"Swap the big background photo on the front page for `IMG_4643.jpg`."*
- *"Make the gold colour a little softer."*
- *"Add a Substack link next to Instagram and YouTube."*

Then double-click `index.html` to check it, and publish when you're happy.

---

## Adding a photo

1. Drag the image file into the **`media`** folder.
2. Ask the assistant to place it, mentioning the file name.

## If something looks broken

Nothing here can break permanently. Every change is saved in history, so
ask the assistant to *"undo my last change"* and it can put things back.
